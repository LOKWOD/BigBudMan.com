THE USEFUL PART

Keep these in your head.

  • Child-resistant packaging and a locked enclosure are different layers. Keep cannabis in its original labeled package inside the locked system.
  • Start with the people, products, devices, and failure cases—not box dimensions or a cannabis-themed finish.
  • Verify the exact lock, relock behavior, key/code recovery, battery state, mounting, allowed environment, interior size, materials, warranty, return deadline, and recall status.
  • A lock can reduce casual access but does not make a container childproof, burglary resistant, fire rated, waterproof, odor proof, or suitable for medicine unless the exact claim has applicable evidence.
  • Test the complete routine while the return window is open: load original packages, open, re-lock, check every authorized user, simulate lost access and power loss, inspect pinch points, and reject unsupported claims.

Keep package resistance and enclosure access separate

Under the federal Poison Prevention Packaging Act framework, “child-resistant” means significantly difficult for children under five to open within the test protocol while not difficult for typical adults to use properly. It does not mean childproof. CPSC advises that even products in child-resistant packaging should be locked away and notes that no childproofing device is completely childproof.

A lockbox does not replace a product's original package, label, lot identity, warnings, or required reclosure. The system is: closed original package → locked enclosure → out-of-sight placement → consistent adult routine. Do not pour products into an unlabeled jar to make them fit.

Check batteries, mounting, and everyday use

  • Keep loose lithium-ion batteries, chargers, hot devices, and damaged cells out of an enclosure unless the exact system is designed for them; a storage box is not a charging cabinet.
  • Use only maker-authorized batteries and power supplies for an electronic lock. Inspect heat, corrosion, leakage, swelling, and low-battery behavior.
  • Anchor or mount only as instructed and only into a suitable structure; do not create hidden electrical, plumbing, fire, rental, or building damage.
  • Check hinges, latches, lid supports, sharp edges, pinch/crush points, small removable parts, coatings, and cleaning instructions.
  • Do not place the box where water, condensation, a stove, direct sun, a heater, or easy vehicle theft defeats the system.
  • Search CPSC recalls using the exact model, date code, and identifying details before purchase and periodically afterward.

Run an acceptance test before the return deadline

  1. Identity: save the exact model, serial/date code, manual, receipt, warranty, and recall result.
  2. Load: place every normal item inside in its original closed package; confirm labels remain readable and products are separated.
  3. Access: have each authorized adult open and relock it without unsafe workarounds; never use a child as a tester.
  4. Relock: test whether the container locks automatically or requires a deliberate action, then verify the state without exposing the code.
  5. Failure: simulate a lost key, forgotten code, low/dead battery, brief power loss, jam, and emergency access using only documented procedures.
  6. Placement: inspect stability, visibility, reach, anchor, clearance, heat/moisture, lid/door motion, and pinch points.
  7. Routine: open, remove one product, close the original package, clear the surface, return it, lock, and verify inventory.
  8. Reject: return the product if evidence, fit, access, recovery, safety, support, or household compliance is inadequate.
